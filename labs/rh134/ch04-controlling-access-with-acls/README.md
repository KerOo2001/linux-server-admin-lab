# RH134 - CH04: Controlling Access to Files with ACLs

## Overview
Practical Linux ACL administration lab on RHEL 9.

## Topics Covered
- Standard Linux permissions
- Access Control Lists (ACLs)
- Viewing ACLs using getfacl
- Modifying ACLs using setfacl
- ACL permission precedence
- ACL Mask and effective permissions
- Default ACL inheritance
- ACL backup, removal, and restoration

## Lab Environment
- OS: Red Hat Enterprise Linux 9
- Hostname: Server.kero
- Lab directory: /opt/acl-lab
- Users: kero-user, dev1

## Practical Exercises Completed
1. Created a root-owned directory.
2. Granted named-user permissions using ACLs.
3. Modified the ACL Mask and observed effective permissions.
4. Configured Default ACL inheritance for dev1.
5. Verified inherited permissions on inherited.txt.
6. Backed up ACLs recursively.
7. Removed Access and Default ACLs.
8. Successfully restored the original ACL configuration.

## Results
All practical exercises completed successfully.
